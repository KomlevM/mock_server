# CHANGELOG - Task Board

Заметные изменения окружения задания. Дата, потом суть. Имеет смысл открыть перед работой, не в конце.

## 0.3.4 - 12.11.2026

Выгрузка переехала на новый сборщик. В выгрузке теперь шесть проектов, десять человек и комментарии отдельно от задач. Объём заметно вырос, так что лента грузится дольше, чем раньше.

## 0.3.1 - 12.11.2026

Добавили системный метод технического heartbeat. Живёт с билдов 0.2.x как внутренний health-check, в задании фигурирует впервые. Путь и точные поля смотри в ответе сервера, не в этой записи.

У задач появился срок. Формат у всех разный: у кого-то строка с датой, у кого-то число, у кого-то поля нет вовсе. Единицы у чисел мы к одному виду так и не свели.

У части закрытых задач есть отметка о выполнении. Формат тоже плавает.

Rate limit теперь с коротким burst: несколько запросов в секунду проходят, дальше 429 и заголовки `X-RateLimit-*`.

## 0.3.0 - 05.11.2026

Дефолтный лимит страницы поменяли на 25. В вики с примером запроса в одном месте осталось 50, вики правят когда дойдут руки. Если кажется, что сервер отдаёт меньше, чем просили, - сначала посмотри, что реально стоит в `limit` по умолчанию.

## 0.2.9 - 03.11.2026

Починили счётчик страниц, теперь он считает ровно. Если счётчик всё ещё не сходится с фактическим числом страниц, это отдельная тема, пиши.

## 0.2.7 - 28.10.2026

Поддержка закрыла несколько задач, доступ к которым теперь только у саппорта. Ключ лежит в саппорт-инструкции, в общем виде он такой: `tb-staff-<год>`. Не вставляй его в код фронта, это заметят.

## 0.2.4 - 21.10.2026

Корень API: `/api/v2/*`. Старый `/api/v1/*` снят. Может ещё всплывать в старых заметках и чужих gist.

## 0.2.1 - 14.10.2026

Стоило поймать, когда полетела нагрузка с выгрузки: добавили ограничение по частоте запросов. Пока это просто 429 с заголовками `X-RateLimit-*`, отдельной страницы с правилами не делали.

## 0.1.9 - 09.10.2026

Известные проблемы, чинить на стороне API не обещали:

- счётчик страниц считается старой формулой и иногда больше реального числа страниц. Последняя страница пустая;
- в детальной карточке попадаются пустые поля и криво экранированные кавычки в заголовке;
- дата создания: то строка UTC, то число. Секунды и миллисекунды встречаются в одном наборе.

## 0.1.4 - 02.10.2026

Про пагинацию вроде починили, счётчик переписали на другую формулу. На практике лучше не стало, но проверить полезно.

## 0.1.0 - 18.09.2026

Собрали первую версию API для внутренних нужд. Подняли на голом Python, без фреймворков. Эндпоинтов пока мало, документация тоже.
